# Super Intelligence (SI) declaration — MANI / Nova 3

In NASA Space Apps 2026, artificial intelligence is referred to as **Super Intelligence (SI)**.

## SI tool used

- **Cursor** ([https://cursor.com/](https://cursor.com/)) — primary assisted development environment for this project.

## How SI was used

- Accelerate writing, debugging, and documenting application code.
- Summarize technical documentation (Horizons, Moon Trek).
- Prototype UI structure and this project documentation.

## What SI did not do

- Invent the mission concept (team chose Lunar Landing Site Navigator / CLPS comparison).
- Create NASA logos or branding.
- Publish unverified numerical results — ephemeris values come from the **NASA/JPL Horizons** API and were checked by the team.
